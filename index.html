Strick Topia Manager

Ein internes Werkzeug für die YouTube-Kanäle von Strick - Topia.

Der Strick Topia Manager zeigt den Betreibern von Strick - Topia die Zahlen ihrer eigenen YouTube-Kanäle in einem Dashboard: Videos, Aufrufe, Wiedergabezeit, Abonnenten, Reichweite und Upload-Planung – für das deutsche Original und die Sprachkanäle.

Nur Lesezugriff. Die App liest Daten über die YouTube Data API, die YouTube Analytics API und die YouTube Reporting API. Sie kann auf YouTube nichts ändern, hochladen oder löschen.

Nur lokal. Alle Daten bleiben auf dem eigenen Rechner der Betreiber. Es gibt keinen Server, keine Cloud, keine Weitergabe an Dritte und keine Werbung.

Nicht öffentlich nutzbar. Die App ist kein öffentlicher Dienst. Es gibt keine Registrierung und keine Konten für andere.
